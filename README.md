# Ecological Niche Modelling of *Caiman latirostris* 

Multi-algorithm ecological niche modelling (ENM) pipeline (MaxEnt, Random
Forest, GAM) for the broad-snouted caiman (*Caiman latirostris*) in South
America, integrating bioclimatic, topographic, and hydrological predictors.

This repository contains the version of the pipeline restricted to the whole
species (*Caiman latirostris*), corresponding to Article 1. For the complete
pipeline, including the five evolutionary units described by Ornellas et al.
(2026), see the companion repository (Article 2).

## Requirements

- R >= 4.2
- Java (JDK) installed and detectable via `JAVA_HOME`, required for MaxEnt
  (`dismo` package)
- R packages: `terra`, `dismo`, `rJava`, `usdm`, `ENMeval`, `randomForest`,
  `mgcv`, `enmSdmX`, `ggplot2`, `dplyr`, `rvest`, `broom`, `raster` (only for
  `MNE00_chelsea_vars.R`, required by `dismo::biovars()`)

## Expected data layout

Scripts use `base_dir <- "./"` as the root. Organise your data relative to
that root:

```
./
├── data/
│   ├── occour/Caimans.csv           # raw occurrence records
│   ├── climate/{tmin,tmax,pr}/      # monthly CHELSA rasters (MNE00 input)
│   └── shapes/calibrarea.shp        # calibration-area polygons (CLADO field)
├── output/                          # generated by the scripts, do not commit
│   ├── predictors/predmod/predmodcrop/Caiman_latirostris/
│   ├── predNA/, pred_vif/, xySWD/, biasSWD/, Fclass_best/, ...
│   ├── Models Maxent/Caiman_latirostris/run_1..20/
│   ├── Models Random Forest/Caiman_latirostris/run_1..20/
│   └── models_gam/Caiman_latirostris/run_1..20/
└── Results New/
    ├── evaluation/{maxent,rf,gam}/
    └── Caiman_latirostris/
```

Folder names containing spaces (`Models Maxent`, `Models Random Forest`,
`Results New`) reflect the naming convention adopted during project
development and were kept for compatibility.

## Execution order

| # | Script | Description |
|---|--------|-------------|
| 0 | `MNE00_chelsea_vars.R` | Compute the 19 bioclimatic (BIOCLIM) variables from monthly tmin/tmax/precipitation rasters |
| 1 | `MNE01_calibra_areav.R` | Crop the full predictor stack to each calibration-area polygon |
| 2 | `MNE02_maskNA.R` | Build an NA mask per species from the cropped predictors |
| 3 | `MNE03_pred_crop.R` | Crop raw predictor layers by hydrographic basin |
| 4 | `MNE04_clear_occurence_corrigido.R` | Clean and spatially thin occurrence records |
| 5 | `MNE05_predictor_selection_corrigido.R` | Predictor selection by VIF (≤ 5) |
| 6 | `MNE06_rescaling_bias_corrigido.R` | Rescale and align the sampling-bias raster |
| 7 | `MNE07_background_biased_pts_corrigido.R` | Generate bias-weighted background points |
| 8 | `MNE08_Fclass_corrigido.R` | Tune MaxEnt hyperparameters via `ENMeval` |
| 9 | `MNE09_sdm_corrigido.R` | MaxEnt: 20 runs x 5-fold cross-validation |
| 10 | `MNE09b_rf_latirostris.R` | Random Forest, same validation design |
| 11 | `MNE09c_gam_latirostris.R` | GAM, same validation design |
| 12 | `MNE09d_maxent_curves_latirostris.R` | MaxEnt response curves and permutation importance (reuses the already-tuned `fc`/`rm`, does not repeat tuning) |
| 13 | `MNE010_evaluation_sdm_corrigido.R` | Evaluation (wAUC, TSS, CBI) of MaxEnt replicates |
| 14 | `MNE011_avar_maps_corrigido.R` | Mean, CBI-weighted, and standard-deviation maps (MaxEnt) |
| 15 | `MNE012_Contrib_vars_corrigido.R` | Variable contribution and statistical tests (MaxEnt) |
| 16 | `MNE014_ensemble_consensus.R` | Consensus across the three algorithms, Schoener's D, and Pearson correlation |

Steps 10-12 (RF, GAM, MaxEnt curves) are independent of one another and can
run in any order after step 9. Step 16 depends on the mean maps produced by
steps 9, 10, 11, and 14.

## Evaluation criteria

Replicates are retained for downstream analyses only if `wAUC ≥ 0.5`,
`TSS ≥ 0`, and `CBI ≥ 0.4` (Hirzel et al., 2006; Allouche et al., 2006).
